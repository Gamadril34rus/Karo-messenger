# Политика конфиденциальности — ЧАРО Messenger

_Действует с 01.01.2025. Последнее обновление: 04.08.2026._

## 1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты персональных данных пользователей мессенджера ЧАРО (далее — «Сервис»).

1.2. Оператор персональных данных — Charo Team (далее — «Оператор»).

1.3. Используя Сервис, вы подтверждаете согласие с условиями Политики.

## 2. Собираемые данные

### 2.1. Обязательные данные
- Номер телефона или email (для регистрации)
- Отображаемое имя
- Пароль (хранится как bcrypt-хеш, необратим)

### 2.2. Данные, предоставляемые пользователем
- Сообщения, медиа, стикеры (зашифрованы E2EE)
- Аватар
- Контакты (только ID, не содержимое адресной книги)
- Геолокация (только при активации функции «Рядом»)

### 2.3. Автоматически собираемые данные
- IP-адрес (для безопасности, не хранится >30 дней)
- Device ID (для управления сессиями)
- Версия ОС и приложения
- Язык и часовой пояс

### 2.4. Данные, которые мы НЕ собираем
- Содержание адресной книги
- SMS / журнал звонков
- Данные других приложений
- Рекламные идентификаторы

## 3. Цели обработки

| Данные | Цель | Правовое основание |
|--------|------|-------------------|
| Телефон/email | Идентификация, восстановление доступа | Договор (ФЗ-152 ст.6 п.1 пп.5) |
| Пароль (хеш) | Аутентификация | Договор |
| Сообщения (E2EE) | Доставка сообщений | Договор |
| IP-адрес | Безопасность, rate limiting | Законная заинтересованность |
| Контакты ID | Функция «Найти друзей» | Согласие |
| Геолокация | Функция «Рядом» | Согласие (явное) |

## 4. Хранение данных

### 4.1. Сроки хранения
- Аккаунт: до удаления пользователем
- Сообщения: до удаления или исчезающие (по таймеру)
- IP-адреса: 30 дней
- Токены сессий: до выхода или истечения (30 дней)
- Backups: 90 дней после удаления аккаунта

### 4.2. Местоположение данных
- Данные граждан РФ хранятся на серверах в РФ (ФЗ-152 ст.18)
- Данные граждан ЕС — в ЕС (GDPR Art.44)
- E2EE-сообщения не расшифровываются сервером

## 5. Права пользователя (ФЗ-152 / GDPR / CCPA)

### 5.1. Права по ФЗ-152
- Право на доступ к своим данным (ст.8)
- Право на уточнение/исправление (ст.8)
- Право на удаление (ст.9)
- Право на отзыв согласия (ст.9)

### 5.2. Права по GDPR
- Right of access (Art.15)
- Right to rectification (Art.16)
- Right to erasure — «right to be forgotten» (Art.17)
- Right to data portability (Art.20)
- Right to object (Art.21)
- Right to restrict processing (Art.18)

### 5.3. Права по CCPA
- Right to know what data is collected
- Right to delete personal information
- Right to opt-out of sale (мы НЕ продаём данные)
- Right to non-discrimination

### 5.4. Как воспользоваться правами
- В приложении: Настройки → Конфиденциальность → Запросить данные / Удалить аккаунт
- По email: privacy@charo.chat
- Срок ответа: 30 дней (GDPR), 45 дней (CCPA)

## 6. Безопасность

- End-to-End шифрование (Signal Protocol)
- TLS 1.3 для транспортировки
- bcrypt (cost=12) для паролей
- RSA-256 JWT для аутентификации
- Pen-testing: ежеквартально
- Уведомление о утечке: 72 часа (GDPR Art.33)

## 7. Передача данных третьим лицам

Мы НЕ передаём персональные данные третьим лицам, за исключением:
- По требованию суда/закона (ФЗ-152 ст.6 п.1 пп.2)
- Processing сервисы (хостинг) — под DPA
- Crash reporting (Sentry) — только технические данные, без PII

## 8. Дети (COPPA)

Сервис предназначен для лиц старше 13 лет.
Мы сознательно не собираем данные детей до 13 лет.

## 9. Изменения

Оператор вправе изменять Политику. Уведомление — за 30 дней до вступления в силу.
