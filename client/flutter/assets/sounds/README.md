# ─── ЧАРО Sounds — ICQ-style Notification Pack ──────────────────────

These sounds are generated ICQ-style notification tones for the Charo messenger.

| File | Frequency | Duration | Purpose |
|------|-----------|----------|---------|
| `icq_message.wav` | 880 Hz | 300 ms | Incoming message notification |
| `icq_send.wav` | 1200 Hz | 150 ms | Outgoing message confirmation |
| `icq_call.wav` | 440 Hz | 600 ms | Incoming call ringtone |
| `icq_online.wav` | 660 Hz | 200 ms | Contact came online |
| `icq_system.wav` | 1000 Hz | 250 ms | System notification |

**Format:** WAV, mono, 22050 Hz, 16-bit PCM  
**License:** Generated in-house — CC0 / Public Domain  
**Note:** These are placeholder tones. For a production release, replace with
real ICQ-style sounds recorded from the original ICQ client or custom-composed
sounds that evoke the classic ICQ aesthetic.

**Font note:** CharoSans font files use Open Sans (Apache-2.0 license by Steve Matteson),
which includes full Cyrillic + Latin character support. Open Sans has no Medium(500) weight;
CharoSans-Medium.ttf uses OpenSans-SemiBold(600) as the closest available weight.
