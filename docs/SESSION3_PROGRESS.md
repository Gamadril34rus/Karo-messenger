## Session 4 (2dc8efc): Critical Bug Fixes & New Screens

### CRITICAL BUG: Register consent fields missing
- **Bug**: `AuthRegisterRequested` didn't include `consentGiven`, `ageConfirmed`, `termsAccepted`
- **Impact**: Server requires `z.literal(true)` for all three → registration would return **400 error**
- **Fix**: Added consent fields to event, BLoC handler, and register_screen

### WebRTC Signaling — Real Implementation
- ActiveCallScreen now uses `GetIt.instance<WsClient>()` for signaling:
  - ICE candidates → `wsClient.callSignal(callId, 'ice', {...})`
  - Offer → `wsClient.callSignal(callId, 'offer', {...})`
  - Answer → `wsClient.callSignal(callId, 'answer', {...})`
- Incoming signal subscription: `_wsSubscription` listens to `WsClient.messages`
- `_handleCallSignal` processes ice, offer, answer, hangup
- Signal type `'ice'` aligned with server's `call.ice` (not `call.ice_candidate`)
